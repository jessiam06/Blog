# Static Site Generator

I've been working on building my own personal website and blog. While I could easily do this with AI or an off-the-shelf site generator, there wouldn't be any fun (or learning) in that.
I've implemented my own custom static site generator that can take in markdown files, parse them, and turn them into blog pages with corresponding cards on my home page. This project is still WIP! All blog posts in the content section are placeholders for now, while I keep developing.
